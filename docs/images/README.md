# Screenshot checklist

SVG files here are explicit image placeholders, not screenshots. Add these real
PNG captures, then change README image links from `.svg` to `.png`. Preserve clear
text at normal display size. Use permitted media; blur signed URLs, account names,
private paths, tokens and any cookie information. Avoid claiming unsupported sites
or successful checks based on a staged capture.

| File | Required content |
| --- | --- |
| `main-dark.png` | Dark main window after analysis: public title, metadata, thumbnail, video quality and destination controls. |
| `main-light.png` | Same main interface in light theme, showing audio mode and bitrate controls. |
| `download-queue.png` | Queue with active progress, speed/ETA, staged or completed tasks and visible row actions. |
| `settings.png` | Settings dialog: defaults, parallel limit, compatibility/artwork, theme and browser-cookie opt-in (disabled). |
| `engine-environment.png` | Engine/Environment versions, tool/capability status and repair/update/diagnostic controls; redact local paths. |
| `about.png` | About dialog with app/Python/Qt/engine versions, MIT and repository. |

Real captures are supplied by the maintainer and remain pending at the Phase 7
documentation gate. No application was launched to fabricate screenshot evidence.
